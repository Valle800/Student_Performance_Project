# Student Performance Project
By Valle - Information Science, Moi University

A simple Python project to calculate student performance.

## What it does
- Inputs marks for English, Computer, Mathematics, Information Science
- Calculates Total and Average
- Assigns Grade: A (70+), B (60+), C (50+), D (40+), F (below 40)
- Shows Pass/Fail status
- Lists all subjects with marks

## How to run
1. Make sure Python is installed
2. Run: python student_performance.py
